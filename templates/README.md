# SuperBuilder Starter Templates

Use these templates to quickly bootstrap new projects with SuperBuilder.

## Available Templates

### SaaS Starter
A full-stack SaaS application template with authentication, dashboard, and billing.
- **Stack**: Next.js + Express + PostgreSQL
- **Features**: Auth, Dashboard, API, Billing

### AI Chatbot
An AI-powered chatbot template with multi-model support.
- **Stack**: Next.js + Express + OpenAI/Ollama
- **Features**: Chat UI, Streaming, Model switching, Memory

### Portfolio
A personal portfolio and project showcase.
- **Stack**: Next.js + Static
- **Features**: About, Projects, Blog, Contact

## Using Templates

```bash
# From SuperBuilder Agent Hub, type:
"Create a new project using the saas-starter template"

# Or manually copy:
cp -r templates/saas-starter my-new-project
cd my-new-project
npm install && npm run dev
```
